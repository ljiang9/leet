# leet

终端 leet-speak 编码/解码器:把普通英文转成"黑客文",也能解回来。
纯 Python 标准库,无第三方依赖。

## 安装

```bash
python3 -m leet "hello world"
```

## 用法

```bash
# 基本编码(默认 level 1)
leet "hello world"            # -> h3ll0 w0rld
leet "elite hacker"           # -> 3l173 h4ck3r

# 从管道读取
echo "hello" | leet           # -> h3ll0

# 反向解码
leet --decode "h3ll0 w0rld"   # -> hello world

# level 2: 符号风
leet --level 2 "you"          # -> `/0|_|
leet --level 2 --decode "`/0|_|"  # -> you

# level 3: 随机变体(--seed 可复现)
leet --level 3 --seed 42 "hello"
leet --level 3 --seed 42 "hello"   # 两次输出相同

# 查看映射表
leet --table
leet --table --level 2
```

## 三个等级

### level 1:经典数字替换(默认)

| 字母 | a | b | e | g | i | o | s | t | z |
|------|---|---|---|---|---|---|---|---|---|
| leet | 4 | 8 | 3 | 9 | 1 | 0 | 5 | 7 | 2 |

**注意:l 故意不替换。** 这是有意为之——经典写法就是 `h3ll0 w0rld`,
而不是 `h3110 w0r1d`。其余字母原样保留。

level 1 的 9 个目标符号互不相同,所以**纯字母输入**下
`decode(encode(x)) == x` 精确可逆。

### level 2:符号风

全字母覆盖,含多字符符号,例如:

| 字母 | c | h | l | n | q | u | y |
|------|---|---|---|---|---|---|---|
| leet | ( | \|-\| | £ | \|\| | (_,) | \|_\| | `/ |

完整 26 字母表见 `leet --table --level 2`。

### level 3:随机变体

每个字母 3 种写法(比如 `a -> 4/@/^`),每次随机挑一种。
`--seed` 固定随机种子,相同种子输出相同,方便测试和复现。
变体字符串在全表范围内唯一,解码按最长匹配优先,是确定的。

## 设计取舍

- 编码时字母大小写不敏感(`A` 和 `a` 都变成 `4`),解码统一输出小写。
- 解码用"最长匹配优先":比如 `|_|\|` 会先匹配 `|_|`(u) 而不是 `|`(l),
  这对多字符符号是必需的。
- 不在映射表里的字符(中文、空格、标点等)原样透传。

## 已知局限(诚实说明)

1. **解码是尽力而为,不是精确逆运算。** leet 符号可能和原文的
   数字/标点撞车:原文里的 `!` 和编码后的 `i` 都是 `!`,
   原文里的 `4` 会被解码成 `a`。只有"纯字母输入"能保证往返一致。
2. **大小写信息丢失。** `0` 解码成 `o` 而不是 `O`;`Hello` 编码再解码
   得到 `hello`。
3. level 3 个别变体在极端输入下可能和"字母+标点"的组合撞车
   (如 `0_` 既是 q 的变体,也可能是字母 o 后面跟了下划线),
   属于最长匹配的已知歧义,不影响正常使用。
